# Explainer Video Workflow

把一条确认稿，做成可以反复修改、复用的讲解视频。

本项目提供 **Skill 操作流程 + 本地状态账本 + 统一时间轴 + Remotion 动画模板**。先固定配音，再让字幕、人物片段与画面跟随同一个时间轴；只改动画时，不重新生成声音和数字人。

这是可运行的制作骨架，不是自动写稿、自动克隆声音、自动发布的一键服务。示例为虚构文字、无声动画，不含真人照片、声音或任何 API Key。

## 快速看效果

需要 Python 3.10+、Node.js 22 LTS 和 npm。首次渲染可能下载浏览器和编码依赖。

```sh
npm ci --ignore-scripts
npm run prepare-demo
npm run check
npm test
npm run render
npm run cover
```

- `out/demo.mp4`：18秒、1080×1920的无声布局示例。
- `out/cover.png`：1080×1920封面。用`src/config.json`修改标题与配色。
- `npm run studio`：浏览器预览与逐帧检查。
- 本地渲染示例不调用生成模型。Remotion自身许可与可能的网络下载见[依赖说明](THIRD_PARTY_NOTICES.md)。

## 怎样变成自己的视频

1. 确认讲给谁听、看完能学会什么，再定口播稿。
2. 用你有权使用的录音生成配音，试听后锁定最终音轨。配音工具需自行选择、配置和确认费用。
3. 从该音轨获得真实字幕时间。示例时间是手工设计的演示，不是语音识别结果。
4. 编辑`examples/edit.json`：所有时间用帧表示，30fps时1秒=30帧；片段范围左闭右开。插入演示后，运行编译命令，字幕和人物位置一起更新。
5. 在`src/config.json`设置场景与触发帧；素材放`public/local/`，该目录默认不提交。设置`narration`为`local/voice.wav`。
6. 按需生成数字人，先看短样片。将片段信息放入`avatars`，人物轨默认静音，不循环补嘴型。
7. 先检查关键帧和有声短片，再渲染整片；保留旧输出，确认字幕、口型、人物遮挡和尾句。

具体字段与例子见[使用指南](docs/WORKFLOW.md)。

## 已实现的优化

| 原来容易出现的问题 | 本项目的处理 |
|---|---|
| 插入一段视频后，各处时间手工修改 | 单一剪辑表编译字幕与人物位置 |
| 生成成功被误当成效果通过 | `generated`与`validated`分开，审核绑定文件哈希 |
| 没有全程数字人，流程就卡住 | `narration`模式让字幕依赖声音，人物可以局部出现 |
| 换了配音还沿用旧口型 | 输入哈希变化使记录过期，人物长度不足时报错 |
| 同一个费用任务重复提交 | 保存任务ID；未决任务不允许换ID登记新任务 |
| 把个人工程整个上传 | 显式公开文件清单、文本扫描、默认忽略本地素材 |

三类示例镜头：素材汇合、步骤逐项出现、保留已确认元素。它们是本仓库独立实现，并非第三方镜头卡合集。新增内容较长时拆幕，不自动缩小字体。

## Skill 使用

让支持本地Skill的工具读取`skills/explainer-video-workflow/SKILL.md`，或把仓库交给编程助手并说：

> 用这个工作流制作我的讲解视频。先核对文案、配音和素材，给出逐段画面及人物出场表；先做有声短片让我看。未经确认不要上传私人素材、调用付费生成或发布。

该Skill不依赖作者电脑的目录或私人技能。状态账本和输出仍需执行者登记，不是后台自动监控。
